# KAVA DELAY

バレーボール等のフォーム確認用に、端末カメラの映像を5〜30秒遅らせて表示するWebアプリです。

## 公開方法（GitHub Pages）
1. GitHubで新しい公開リポジトリを作成します。
2. このフォルダ内の5ファイルをアップロードします。
3. Settings → Pages → Deploy from a branch → main / root → Save。
4. 発行された `https://ユーザー名.github.io/リポジトリ名/` をGoogle Classroomに貼ります。

## 使用上の注意
- HTTPSで公開してください。カメラは安全な接続でのみ利用できます。
- 初回起動時はインターネット接続とカメラ許可が必要です。
- 一度読み込んだ後はキャッシュされますが、iPhone/iPadではSafariのタブから使う方法を推奨します。
- 映像はアップロードせず、端末内で一時処理します。
- 端末・OSにより1秒程度のつなぎ目や遅延差が生じる場合があります。来週の本番前に使用端末で確認してください。
